# Spaced Review Workflow

Use this when learning state is active and the learner is studying over time.

```text
completed step -> review prompt -> retry date/category -> later retrieval
```

## Review Categories

- soon: same session or next session,
- later: after the idea feels stable,
- exam/project: before the stated deadline.

## Review Entry

```text
## [Concept]

Prompt: [short retrieval question]
Why it matters: [one line]
Review: soon | later | exam/project
Last result: new | correct | missed | retaught
```

Do not promise notifications or reminders unless the host tool can actually send them.
