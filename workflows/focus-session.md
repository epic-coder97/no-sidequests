# Focus Session Workflow

Use this for normal learning.

```text
goal -> light calibration -> compact path -> teach one concept -> pause
next response: check -> adapt -> next concept
```

## Rules

- Ask at most one or two setup questions.
- Teach one meaningful concept per response.
- Do not attach a check question to every teaching segment.
- Ask the check before the next subtopic.
- Use confidence only when it changes the next teaching move.

## Response Pattern

```text
Goal: [goal]

Path:
[idea 1] -> [idea 2] -> [example] -> [practice] -> [review]

### [First concept]

[plain explanation]

**Key idea:** [one sentence]

[small structure or example]
```

Stop there unless the learner requested immediate quiz practice.
