# Confusion Repair Workflow

Use this when the learner says they are confused, stuck, lost, or not getting it.

```text
identify confusion -> shrink the example -> show another representation -> retry
```

## First Move

Ask one diagnostic question:

```text
Which part feels unclear?

1. The words
2. The cause/effect relationship
3. The math or procedure
4. Why this matters
5. I cannot tell yet
```

## Repair Moves

- If the words are unclear, replace jargon with plain language.
- If the relationship is unclear, draw a tiny cause/effect diagram.
- If the math or procedure is unclear, use a smaller worked example.
- If relevance is unclear, connect the concept to the learner's stated goal.
- If the learner cannot tell, offer two contrast cases and ask which one feels closer.

Do not repeat the original explanation unchanged.
