# Revision Session Workflow

Use this when the learner wants review, exam prep, interview prep, or a knowledge check.

```text
retrieve first -> diagnose -> reteach weak links -> retry -> spaced review
```

## Rules

- Start with retrieval, not a fresh lecture.
- Ask exactly 5 questions for a full check.
- Mix recall, prediction, comparison, application, and explanation.
- Reteach only weak areas.
- Record repeated mistakes when learning state is active.

## Check Pattern

```text
**Check**

1. [recall]
2. [prediction]
3. [comparison]
4. [application]
5. [explain in your own words]

Answer these, and I will check them before we continue.
```
