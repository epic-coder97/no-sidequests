# Study From Material Workflow

Use this when the learner provides source material, a folder, pasted text, a link, textbook, syllabus, board, grade, chapter, or exam source.

```text
source -> teacher analysis -> short source map -> learning path -> teach one concept -> pause
next response: check from source -> adapt -> continue
```

## Source Intake

Accept the easiest form the learner has:

- broad curriculum label, such as CBSE Class 10 Science,
- file or folder path,
- pasted text,
- link,
- PDF, DOCX, slides, screenshot, or image if the host tool can read it.

Do not require `.md`. Prefer `.md` or `.txt` only when the learner asks where to put material.

If the learner mentions a curriculum but gives no source, ask one light question:

```text
Do you want to follow a specific source?

1. I will provide a file or folder
2. Use the standard textbook or syllabus
3. Start from the broad topic
```

## Source Rules

- Inspect only the requested source first.
- Treat provided material as the primary source.
- Use outside knowledge only to clarify, fill small gaps, or verify current/curriculum details.
- Label outside context clearly.
- If the material cannot be read, ask for the smallest useful section in readable form.

## Teacher Analysis

Before teaching, analyze the source like an expert teacher:

- topic map,
- prerequisites,
- important definitions,
- confusing terms,
- examples already present,
- analogy candidates,
- likely misconceptions,
- exam or application points,
- first concept to teach,
- check and review prompts.

Most of this is planning context. Show only a short source map to the learner.

## Student-Facing Start

```text
I found these parts:

1. [section]
2. [section]
3. [section]

We will start with [first concept] because [short reason].
```

Then teach one concept and pause.
