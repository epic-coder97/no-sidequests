# Example: Recovering from Confusion

Topic: electric current

Learner says:

> The current stays the same because the same amount of charge passed.

### The missing piece is time

You correctly tracked the **amount of charge**. Current, though, is a rate, so time is part of the relationship.

```text
current = charge / time
```

If the same charge takes **twice as long**, the amount passing each second is half as large.

**Analogy:** 20 cars passing a checkpoint in 10 seconds is a higher traffic rate than the same 20 cars passing in 20 seconds.

The number of cars is unchanged; the **rate** changed.

**Try again:** same charge, but 3× the time. What fraction of the original current remains?

## Teaching note

Do not restart the entire lesson. The learner already understands one component: amount of charge. Repair only the missing dependency on time, then re-test that relation.
